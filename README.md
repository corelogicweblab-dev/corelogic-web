## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Deploy to Netlify

See **[NETLIFY_DEPLOY.md](./NETLIFY_DEPLOY.md)** for step-by-step GitHub → Netlify setup.

## Tech stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- Framer Motion, GSAP, Three.js
- Netlify serverless functions (API routes)

## Features

- Cinematic hero with neural network & particles
- 10 services, 5 solution showcases, tech stack
- Live Support chat (Tagalog/English, detailed replies)
- Contact form API + direct email/phone links
- SEO: sitemap, robots, Open Graph, JSON-LD

## Environment

Copy `.env.example` to `.env.local` for local overrides. Production defaults are baked in for contact info.
